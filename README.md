# WordJot · 安卓课堂单词本

WordJot让你在课堂上输入一个词就继续听课。输入先存入手机的 SQLite 单词本，查词在后台进行。无需账号、API Key 或订阅。

## 安装与第一次记录

1. 在 [GitHub Releases](https://github.com/r1uda/WordJot/releases/tag/v1.2.0) 下载 `WordJot-1.2.0.apk`，在安卓手机上打开并安装。支持 Android 8.0 及以上。旧版可直接覆盖安装，已有词条和学习进度会保留。
2. 进入 **课堂速记**，直接输入 `apple`、`look up` 或「课堂」。按发送或输入法的发送键。输入框立即清空，可继续输入。左下角提示「已记录」表示数据已写入单词本。
3. 用安卓返回手势或返回键退出。部分输入法会先收起键盘，再返回一次即可。回到 **单词本** 搜索刚才的词。
4. 点词条可收藏，点 **编辑词条** 可改英文、释义、分类、音标、词性、例句和其他英文表达。同一个英文词的大小写、首尾空格和连续空白会自动归一化。汉英查询得到同一英文时可合并。

## 单独查词

首页点 **查词**，输入英文、中文或短语并按「查询」。英汉离线词库含 769,032 个词条，例如输入 wedgie 能看到口语义和鞋类义，输入 necrophilia 可查到「恋尸癖」。安卓版本在离线词库未命中时尝试在线查义。浏览结果不会加入学习队列。想背这个词时点 **加入我的单词本**，以后可以从同一位置打开已保存的词条。

## 背诵、测试与统计

**我的单词本决定背什么。** 课堂输入的词直接收进来。首页「四六级选词库」提供另一种收词方式，点「不会，加入我的单词本」才收录。两种来源共用首页「背我的单词」、测试、错词和间隔复习。初次安装时，个人单词本为空。

- 在课堂输入框上方点「已记单词」就能展开按添加时间倒序排列的记录。中文默认显示，点「隐藏中文」可自测，点「显示中文」可恢复。收起记录后也能看到刚录入词的释义，尚未查到时会提示。切换时输入框保留草稿。
- 四级与六级都支持「从基础开始」「跳过基础」「只练挑战词」。默认跳过基础。词库参考 ECDICT 的考试标签和词频粗分难度，连续两次跳过会提高推荐难度，连续两次收词会在所选下限内降低难度。
- 浏览卡片或看中文不会修改个人单词本。「太简单，跳过」会记住选择，同一词跨库也会跳过；可从「已跳过的词」恢复。个人本里已经有的词会自动从候选中排除。选词偏好和跳过清单随 JSON 备份保存。

- **背我的单词** 优先取个人本里已到期的词，每轮最多 20 个。正面只显示英文，轻点后显示释义并朗读。选择「不认识、模糊、认识、已掌握」中的一项即可进入下一张。当前没有到期词时可以自由背诵。
- **单词测试** 提供英译中、中译英、选择题、听音辨词和错词专项，每轮最多 10 词。每次提交都会保存成绩，完成一轮可以查看正确率、正确答案和每个词的掌握程度。
- 英译中写出一种释义即可。判分支持词典的多个义项、常见同义词、词性前缀和标点差异。中译英接受主词和词条中保存的其他表达，忽略大小写与多余空格。可在词条编辑中补入自己课程里的译法。
- 选择题从已存词条中优先挑选词性相同、释义不同的选项。只有两个或三个合适词条时，生成对应数量的选项。听音题可以重复播放。
- 测试答错会加入错词本，之后在任意测试中答对该词会移出专项，历史错误次数仍保留。首页「今日待复习」统计当前已到期且有释义的词。学习正确率将测试答对、背诵选择「认识」或「已掌握」计为正确。
- 统计页显示最近七天的新增词数和复习次数，以及各掌握等级的词数。

## 离线使用与备份

首次启动使用内置词库。记录英文和中文、离线查到的词条、所有已有卡片、测试和统计均可断网使用。首次查词会在后台准备词库，需要额外约 80 MiB 手机储存空间。系统 TTS 优先使用已安装的离线美式英语声音。若没有声音，请从 **设置 → 英语朗读 → 系统设置** 安装或启用英语语音包，同时检查媒体音量。

本地未命中的词进入持久队列。网络可用后 Android 会安排查询，失败后自动延长重试间隔，也可以在设置中点 **立即重试**。释义完成前，词条仍可搜索、修改或删除。「待查」筛选可查看队列。外部服务可受限流、地区网络或系统省电策略影响。需要马上背诵的词可以直接编辑释义。

在 **设置 → 导出 JSON** 中选择保存位置。备份包含词条、原始输入别名、学习时间、逐次评分、复习进度和分类。**导入备份** 会合并缺少的词条，遇到重复词保留手机现有版本。新装后导入可完整恢复学习记录。导入失败会回滚本次数据库变更。卸载或清除应用数据前请先导出。
